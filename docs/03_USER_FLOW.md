# LOKA USER FLOW

## User Journey

### Step 1 — Open App

User membuka aplikasi LOKA.

↓

### Step 2 — Home Screen

User melihat:

- AI Trip Planner
- Budget Estimator
- Saved Trips
- AI Assistant (RAILA)

↓

### Step 3 — Create New Trip

User mengisi:

- Kota Asal
- Kota Tujuan
- Tanggal Berangkat
- Tanggal Pulang
- Jumlah Penumpang
- Budget
- Preferensi Wisata

↓

### Step 4 — AI Processing

LOKA AI akan:

- Membuat itinerary
- Menghitung budget
- Memberikan rekomendasi wisata
- Menyusun timeline perjalanan

↓

### Step 5 — Trip Dashboard

User melihat hasil:

- Total Budget
- Timeline
- Itinerary
- Hotel Recommendation
- Tourist Attraction
- Food Recommendation

↓

### Step 6 — Chat with RAILA

User dapat bertanya:

- Tempat wisata terbaik?
- Hotel murah?
- Kuliner khas?
- Tips perjalanan?
- Budget alternatif?

↓

### Step 7 — Save Trip

Perjalanan disimpan ke akun pengguna.

↓

### Step 8 — Reminder

LOKA mengirim:

- Reminder keberangkatan
- Reminder check-in
- Reminder wisata
- Reminder pulang

↓

### Step 9 — Trip Completed

Perjalanan selesai.

LOKA menampilkan:

- Total pengeluaran
- Ringkasan perjalanan
- Riwayat perjalanan
